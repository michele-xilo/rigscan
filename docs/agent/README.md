# docs/agent

Notes for AI coding agents working on Rigscan. Not user documentation: the
human-facing docs are the top-level `README.md` and, later, the docs site.

Read in this order:

1. [context.md](context.md): what Rigscan is, scope, roadmap, market evidence.
2. [decisions.md](decisions.md): decisions already made and why. Do not
   re-litigate these without new evidence.
3. [conventions.md](conventions.md): how to work in this repo.

Keep these files current. When a decision changes, edit `decisions.md` in the
same change and say why.
